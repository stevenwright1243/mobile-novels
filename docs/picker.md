# The picker window

The picker (`index.html`, `src/renderer.ts`): its sidebar, pages and region editor.

## Layout

two pages built by `vite.renderer.config.mts` (multi-page `rolldownOptions.input`), each in its own window: `index.html` → `src/renderer.ts` (the picker: a sidebar with "Your games", rows showing the game's .exe icon (`icon` in `ProfileSummary`, a `data:` URL from `app.getFileIcon`, cached per .exe in main; its first letter if none; faded while not running) that a click picks if running or starts if not, with a ✕ that force-closes a running one and "Open · muted" on running games not being played, the "Open windows" `<details>`, which folds once a game is picked, and the phone status and PC / Phone switch at the bottom; on the right a top bar with the game's title, Short name box and Save, and tabs for the pages Regions (the region editor and preview), Style (the Menus sheet's Sizes panel, `src/picker-sizes.ts` drawing its sample from the preview at the portrait's size, and under it the Look card: theme, border and arrow selects), Input (the Menus sheet's Input Settings panel, with its own Save / Reset) and Debug (debug mode only). No zoom pad, q.Save / q.Load buttons or Log, which are the portrait's) + `src/region-editor.ts` (region outlines with move/resize handles and snapping) + `src/preview-zoom.ts` (zoom by laying `#zoom-box` out bigger inside the scrolling `#preview-area`, not a CSS transform, so the editor's `getBoundingClientRect` maths still holds) and `portrait.html` → `src/portrait.ts` (the streamed portrait view). Both run with Node integration disabled and share `src/preload.ts`. `desktopCapturer` is **not** available here; get source IDs from main over IPC, then capture with `playCapture()` from `src/capture.ts`.
